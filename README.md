# ASMR 日中翻译词组包

**推荐稳定包仍为 v0.0.1；v0.0.2 是需主动选择的概率矩阵实验包，要求播放器至少 v0.1.5。** 网站与词组包独立编号，旧版本和 tag 保留。

v0.0.2 保留 v0.0.1 的 5,433 项词义偏好，增加 1 个日文词形的 4 个许可候选、20,000 项中文基础频率、15,000 条中文搭配转移。浏览器按译法概率、搭配、独立组支持量和基础优先级比较整句候选；证据或分差不足、受保护语义及预算超限时使用冻结基线。评分仅是加权比较，不是正确率。

本轮累计 1,688 个作品目录、12,379 份去重文件；可靠日中对照只有 **971 对、5 个独立组**，实际进入译法训练仅 **2 对、2 组**，中文单语训练 878 组。开发集 924 对／2 组、新测试集 45 对／1 组；与 v0.0.1 结果一致，没有观察到质量提升。300 组／50,000 对及新测试 50 组／5,000 对的门槛未达到，不替换默认推荐包。纯中文字幕只学习中文搭配，没有生成日文源句。

在 v0.1.5 播放器的“本地日语”中先检查更新，再选择 **v0.0.2 · 实验版** 安装；“推荐稳定版”继续指向 v0.0.1。也可从 [v0.0.2 实验版 Release](https://github.com/RoGent-Z/asmr-zh-translation-pack/releases/tag/v0.0.2) 下载 JSON 手动导入。默认折叠的“词组评分”解释采用或回退原因；JSON 带诊断，SRT/VTT 为普通字幕。

以下 v0.0.1 说明保留作为稳定包依据。

供[ASMR 原声播放器](https://rogent-z.github.io/asmr-local-player/)在浏览器本机使用的可选词组包。独立版本管理，无需账号、Key或收费翻译服务。

**首版实际包含5,433项词义偏好、0条整句短语记忆。** “词组包”是安装单元名称，不代表5,433条日中整句翻译。它基于中文语料的用词分布，从既有日中词典**同一义项**的中文候选中选取偏好。并非机器翻译模型，不保证语序或语境正确。

## 安装

在播放器v0.1.4及以后版本的“本地日语”面板点击**安装／更新词组包**，默认安装推荐稳定版，也可检查更新后选择历史版本。网页先校验兼容性、字节数、SHA-256和包结构，再写入浏览器缓存。失败保留旧包。之后刷新会恢复已安装包。原安装更新追加构建已正式改号为v0.1.4；旧v0.1.3仍可手动导入JSON，包版本和最低文件兼容版本不变。

也可从[Release v0.0.1](https://github.com/RoGent-Z/asmr-zh-translation-pack/releases/tag/v0.0.1)下载`asmr-ja-zh.json`，在网页点击“导入本机学习包”。可单独移除，不必重下载基础语言库；清除语言缓存会同时清除包。安装包不包含基础词典或ASR模型。

## 文件与版本

- `packs/asmr-ja-zh.json`：当前开发版数据（v0.0.2 实验）；稳定版从 v0.0.1 固定 tag 获取。
- `catalog.json`：安装目录，包含已发布版本及不可变tag下载地址、SHA-256、大小和兼容要求。
- `FORMAT.md`：后续版本发布约定。
- `tools/verify.mjs`：Node 22+校验，运行`node tools/verify.mjs`。
- `LICENSE` / `NOTICE.md` / `UPSTREAM-NOTICE.txt`：数据完整许可、署名和修改说明。

稳定包版本为**0.0.1**；包格式版本为数字**1**；首次兼容播放器**0.1.3**、词典**ja-zh-v1-20261013**，三者用途不同。旧tag不改写。新包通过目录发布后，网站无需为每次词义更新重新部署；如改变词典ID体系或包格式，应提高兼容要求并先更新网站。

## 方法与限制

原始本机样本来自188部作品、2,326份去重字幕。词义偏好仅使用训练分组：至少10个独立作品/共享内容组，支持量至少为原候选4倍、第二候选2倍；同一作品和共享字幕组不跨训练/开发留出。每个公开目标已逐项核对属于上游许可词典的同一义项。

中文单语统计不会生成日文源句。本版没有达到跨作品可靠性门槛的整句记忆。开发对照仅一部完整作品，调整词义后有参考词命中增加也有反向情况；不提供“翻译准确率提高”的结论。基础词库仍可能多义误选、语法不自然或保留未匹配原文。

原字幕、作品清单、数据库、逐句对照、本机路径和音频不在本仓库。公开包仅含许可词义及汇总支持数。
